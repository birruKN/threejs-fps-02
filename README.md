EMBER YARD — a round-based tactical FPS built with three.js. Two bomb sites, a buy-phase economy, and bot teams fight over a dusk industrial freight yard: Vanguard defend, the Jackals attack and plant. First to 5 rounds wins. Three weapons plus a frag grenade, Kevlar, headshot multipliers, recoil and spread that punish firing on the move, and bots that run routes, hold positions, plant and defuse. Static files only — no build step, no network.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
